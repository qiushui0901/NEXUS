# 真实 RAG 评测基线

## Goal

建立能够代表公司开发人员真实提问方式的需求、代码和联合检索评测基线。

## Requirements

- 评测问题不得主要依赖类名、方法名等答案泄漏。
- 覆盖业务语义、跨文档、多跳、历史版本、无答案和需求代码联合问题。
- Gold 必须经过人工确认，并记录项目、版本、commit 和证据 ID。
- 输出 Recall、MRR、nDCG、无答案准确率、降级率和 P95 延迟。

## Acceptance Criteria

- [ ] 冻结并版本化真实评测集。
- [ ] 提供可重复执行的基线命令和机器报告。
- [ ] 关键指标进入质量门，退化时构建失败或明确阻断发布。

## Out Of Scope

- 不使用线上失败结果自动生成未经人工确认的 Gold。
