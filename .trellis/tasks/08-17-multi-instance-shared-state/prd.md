# 多实例共享状态

## Goal

确保 NEXUS 多实例部署时的索引任务、Wiki、策略、评测数据和审计状态保持一致。

## Requirements

- 盘点并分类所有本地文件、SQLite 和内存状态。
- 对需要强一致的任务协调和 active policy 使用共享权威存储。
- Wiki、数据集和实验报告具备共享持久化和版本约束。
- 本地实现继续服务开发环境，生产环境必须显式选择共享后端。
- 迁移过程可观测、可验证、可回滚。

## Acceptance Criteria

- [ ] 两个实例读取相同 Wiki、策略和任务状态。
- [ ] 同一项目不会被两个实例并发发布不同索引。
- [ ] 单实例故障后任务可恢复且不会重复发布。
- [ ] 提供迁移、备份、恢复和回滚文档及集成测试。

## Out Of Scope

- 不在首期实现跨地域多活。
