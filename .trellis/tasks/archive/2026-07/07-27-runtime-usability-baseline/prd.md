# 可运行基线与首次使用修复

## Goal

让 NEXUS 从“需要了解内部细节才能勉强运行”变为可以按明确入口启动、检查状态并进入核心模块的本地产品。

## Requirements

- 提供可靠的一键启动、停止和状态检查脚本；自动加载本地 `.env`，兼容当前 Maven 产物名，不依赖系统 Maven。
- 服务默认仅监听本机回环地址，避免未启用鉴权时暴露到局域网。
- 根路径进入平台首页，而不是直接进入依赖最重的代码工作台。
- 首页展示 Wiki、版本中心、代码工作台入口，以及 Qdrant、Ollama、BGE、需求知识和代码索引的真实状态。
- BGE 缺失必须显示“可降级/未连接”，不能让整体健康状态伪装为全部正常。
- 代码索引为空时必须明确提示建立索引，并展示当前配置的 collection；不得自动映射到版本不明的旧索引。
- 完整代码索引必须在后台运行并提供状态查询；浏览器不得等待数分钟的同步请求，重复点击不得启动同一项目的并行任务。
- 嵌入失败不能先删除旧索引；大型符号必须限制为模型可接受的片段，并减少类正文与方法正文的重复向量化。
- `.env.example` 和 README 必须包含代码 collection 与一键启动说明。
- 不提交 `.env`、Qdrant 数据、向量、需求正文快照或本地凭据。

## Acceptance Criteria

- [x] `./scripts/nexus.sh start` 能加载 `.env`、启动本地 Qdrant 和当前版本应用，并等待应用就绪。
- [x] `./scripts/nexus.sh status` 能区分运行、降级、未运行及代码索引为空。
- [x] `./scripts/nexus.sh stop` 能停止由脚本启动的应用和 Qdrant。
- [x] `/` 打开 NEXUS 平台首页，三个核心模块均可进入。
- [x] `/api/runtime/status` 返回依赖状态、项目知识统计、代码 collection 和索引数量。
- [x] BGE 未运行时首页明确标记为可选降级项，Wiki 和版本中心仍可使用。
- [x] 工作台启动完整索引后立即返回，并持续展示 `RUNNING / COMPLETED / FAILED`；已有索引在重建期间可检索。
- [x] 后端测试、静态页面契约测试和真实启动冒烟检查通过。

## Constraints

- 保持原生 HTML/CSS/JavaScript，不引入前端构建系统。
- 不删除或迁移本地旧 Qdrant collection。
- 不把未验证的旧代码索引当作当前目标版本索引。
