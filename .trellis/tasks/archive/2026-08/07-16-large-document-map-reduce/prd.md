# 大文档 Map-Reduce

## Goal

避免需求评审因全文字符截断而遗漏模块，并保留覆盖范围和部分失败信息。

## Requirements

- 小文档继续走快速路径。
- 大文档按路径模块优先、父块顺序批次兜底分组。
- Map 生成候选问题和证据，Reduce 去重、合并证据、排序和限量。
- 每批有状态、覆盖范围、重试和失败 warning；全部失败遵循核心失败契约。

## Acceptance Criteria

- [ ] planner 对有模块路径和无模块路径均有测试。
- [ ] 大文档覆盖所有批次，不依赖尾部截断。
- [ ] 单批失败可见，成功批次仍可合并。
