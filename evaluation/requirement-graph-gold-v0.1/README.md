# 需求语义图金标数据集 v0.1

## 状态

这是第一版**金标候选集**，不是已经完成双人复核的最终 Gold。数据来自需求快照、QA 确认表、存疑表和代码知识页。当前所有记录的 `annotation.status` 为 `HUMAN_REVIEW_REQUIRED`，完成复核后才可作为正式评测 Gold。

## 覆盖场景

- 成长基金需求事实；
- 跨片段组合证据；
- 太古战场物资记录；
- 部队皮肤升星；
- QA 已确认事实；
- OPEN 存疑和文档冲突负例；
- 代码已验证事实；
- 成长基金与成长特价礼包不可合并边界。

## 复核规则

1. 只确认原文明确支持的实体和关系。
2. 成长基金和成长特价礼包必须保持独立，不能因名称相似合并。
3. QA/产品确认只能标记为 `QA_CONFIRMED`，不能直接标记为 `CODE_VERIFIED`。
4. `DOUBT_NEGATIVE` 默认不能产生已确认关系，只能保留 OPEN 存疑。
5. 需求与代码冲突时分别保存 Requirement Claim 和 Code Fact，并产生漂移，不覆盖代码事实。
6. 多片段共同支持的关系使用 `COMPOSITE_SUPPORTED`，不能伪装成 `DIRECT`。
7. evidence 中的 quote 必须能在指定来源中回查。

## 正式 Gold 完成标准

- 每条记录至少一名主审；
- 跨窗口、负例、代码边界样本由第二名复审；
- 分歧样本记录原因；
- `GOLD_ACCEPTED` 进入正式评测；
- `GOLD_REJECTED` 保留为错误分析负例。
