# 数据导出申请与双阶段授权

## 导出申请的审核边界

数据导出申请用于分析人员获取受控数据集，与内容发布或代码上线审批无关。申请必须声明数据集、字段范围、时间范围、使用目的、接收人和销毁日期。系统先执行策略预检，检查申请人是否具有查询权限、字段是否包含敏感分类以及结果规模是否超过导出上限。预检通过不代表已经批准，只表示申请可以进入人工审核。

普通内部指标由数据负责人单人批准；包含个人标识、联系方式或精确位置时，需要数据负责人和隐私负责人依次确认。两个审核人的结论绑定同一字段清单摘要。申请人在审核期间新增字段或扩大时间范围会使全部结论失效；仅缩小范围时保留数据负责人结论，但隐私负责人仍需确认最终摘要。等待两小时后提醒当前审核人，等待十二小时后通知数据治理值班，不自动批准。

驳回申请可以修改后重新提交，但新提交使用新的授权轮次和新的用途声明。系统在页面上展示历史驳回原因，不能把旧批准状态复制到新轮次。批量导出接口同样经过策略预检和人工审核，服务账号不能借助后台任务绕过流程。紧急调查可启用快速路径，但至少要有一名隐私负责人实时确认，并在四小时内补齐数据负责人复核。

批准完成后，导出作业再次核对申请人权限、字段摘要、数据版本和销毁日期。任何一项不一致都停止作业并要求重新申请。实际生成的文件采用独立密钥加密，下载者必须是申请中列出的接收人。批准记录不能用于多个数据集，也不能把一个项目的授权扩展到另一个项目。作业分片失败时可以重试相同分片，不得扩大查询条件。

下载链接从文件生成时开始计时，内部非敏感导出有效六小时，敏感导出有效一小时。链接失效后文件进入等待销毁状态，重新下载需要重新生成链接，但不一定重走人工审批；只有授权本身过期或字段发生变化时才重新审核。这里的链接时效不是审计导出文件的二十四小时规则，也不是会话保留时间。

## 作业执行、销毁与追踪

导出作业状态包括排队、执行、待校验、可下载、已失效和已销毁。进入可下载前要校验记录数、字段数、文件摘要和加密元数据。校验失败时文件不可见，作业转入失败状态并通知申请人。重试沿用原申请编号和授权摘要，产生新的作业尝试号，便于区分执行故障与授权变化。

销毁任务每天扫描已过期文件，先撤销下载令牌，再删除对象存储内容，最后记录不可逆删除凭证。处于合规保全中的导出文件暂停自动销毁，但下载权限仍然关闭。保全解除后从新的销毁计划继续，不恢复旧链接。人工延长保存期限需要数据治理工单，延长期限只影响文件，不改变源数据的保留政策。

审计事件包含申请、预检、每次审核、作业启动、分片重试、下载、链接失效和销毁。检索事件至少限定申请人所属组织与数据集，隐私字段默认脱敏。导出审计的查看权限与导出数据权限分开授予，获得下载许可的人不自动获得完整审计访问。审计事件写入失败时停止生成新下载链接，但不会删除已经完成的文件。

限流按申请人和数据集统计并发作业，软限制只延后排队，硬限制拒绝创建新作业。服务端时间决定窗口，客户端提交时间仅用于展示。监控关注队列长度、平均生成时间、敏感字段占比、链接下载次数和销毁延迟。告警不能自动改变审核状态，也不能替代隐私负责人结论。

恢复演练使用脱敏样本和不可访问的模拟链接。恢复导出服务时，先重建作业状态，再校验对象存储中的文件摘要，最后恢复通知。系统不得从通知消息推断批准已经完成，也不得因为文件存在就重新开放下载。所有恢复操作必须引用演练编号或事故编号。

## 验收矩阵与隐私控制

验收场景覆盖字段从非敏感升级为敏感、申请人在审批中失去权限、两个审核人对不同摘要做出结论、作业分片部分成功和链接在下载过程中到期。测试必须核对授权摘要、实际查询、文件列头和审计事件四者一致。仅检查申请状态不足以证明导出范围正确。

隐私分类服务不可用时，新的字段申请一律停止，已经批准且摘要未变化的作业可以按照缓存分类执行，但缓存超过有效期后同样停止。分类恢复后重新核对待执行申请。人工覆盖分类需要隐私治理工单和到期时间，不能永久降低字段级别。

对象存储写入成功但作业状态提交失败时，恢复任务通过作业尝试号定位孤立文件。摘要一致则补交状态，摘要不一致则删除孤立文件并重新生成。恢复过程不会创建新授权。通知发送失败只重试通知，不重新生成链接，避免多个有效链接并存。

接收人下载前再次校验组织成员关系和申请状态。转发链接给未列出的用户仍然拒绝。下载次数、来源网络和文件摘要进入审计，但不记录文件正文。大文件采用分段下载令牌，每段属于同一链接有效期，不能通过持续请求无限延长。

安全测试包括修改字段参数、替换数据集标识、复用他人申请、猜测下载编号和重复销毁回调。容量测试验证大量排队作业不会绕过并发上限。时间测试使用可控时钟覆盖一小时、六小时和授权到期边界，禁止依赖真实等待。

上线前核对分类规则版本、审核角色、加密密钥、对象生命周期、销毁任务和告警接收人。规则调整只作用于新申请；已经批准但尚未执行的申请若涉及提高敏感级别，则必须重新审核。任何例外都要有明确到期时间和审计依据。
