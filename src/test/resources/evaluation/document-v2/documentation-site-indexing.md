# 文档站点抓取与搜索索引

## 站点注册和页面发现

文档站点索引用于产品帮助与内部手册搜索，不扫描源代码符号。首次注册站点时校验根地址、允许域名、抓取范围、robots 策略和访问方式，不要求代码仓库默认分支。访问凭据只能读取已授权页面，抓取器禁止访问根地址之外的链接。

页面发现从站点地图和已批准入口开始，按照规范化 URL 去重。URL 片段、跟踪参数和默认端口不参与页面标识，语言和版本路径保留。抓取器记录响应摘要、内容类型、更新时间和出链。客户端页面显示的本地时间不作为增量依据。

增量抓取以最后成功页面清单和服务端响应标识为起点。页面响应标识未变化时跳过正文解析；标识缺失时比较内容摘要。只依赖更新时间可能漏掉错误配置页面，因此每周执行一次低速完整核对。完整核对不会清空当前可查询索引。

页面删除返回明确不存在并连续确认两次后，索引标记待删除。重定向把旧 URL 保留为别名并指向新页面。标题修改不视为页面重命名，内容摘要变化后更新段落。删除和重定向只清理文档页面向量，不涉及代码符号关系。

解析器提取标题、层级、正文、代码示例和版本标签，过滤导航、页脚和重复侧栏。单页失败进入隔离列表，不阻塞其他页面。跨站点相同段落按来源分别保存，避免一个站点的权限变化影响另一个站点。

## 发布切换、失败和恢复

一次抓取生成候选索引，只有页面数量、失败比例、语言分布和抽样查询都通过后才切换读取别名。失败时保留上一版索引继续查询，并显示站点同步陈旧。候选索引不会被当作正式版本，也不会覆盖上一版的页面清单。

抓取服务恢复时读取最后成功清单和未完成队列。重复页面任务按照规范化 URL 与内容摘要幂等。旧实例恢复后检查任务租约，不能继续写已经关闭的候选索引。索引写入完成但别名未切换时，恢复流程重新校验而不是直接发布。

访问权限在查询时和索引时都执行。页面从公开变为受限后立即使缓存失效并更新访问标签；在重新抓取前查询层采用更严格的最新策略。站点管理员只能管理所属站点，搜索运营可以查看匿名化质量指标。

审计事件包括站点注册、范围修改、抓取、页面隔离、候选校验、别名切换和权限变化。监控包括抓取延迟、页面失败、陈旧站点、候选校验、重定向环和权限拒绝。告警不会自动扩大抓取范围或绕过 robots 策略。

测试站点包含模拟页面、重定向、删除、权限变化和重复导航。测试验证规范化 URL、候选失败、旧索引保留和恢复租约。站点地图、页面响应标识和 URL 别名不能替代代码仓库提交、制品坐标或向量与符号关系清理规则。

## 内容边界与验收矩阵

规范化 URL 保留具有业务含义的版本和语言参数，移除跟踪参数、片段和默认首页别名。站点可以声明额外保留参数，但必须经过抓取范围审核。两个规范化后相同的页面选择一个主地址，其他地址作为别名，不重复建立正文向量。

验收用例覆盖站点地图分页、重定向环、软删除页面、语言切换、权限从公开变为受限、响应标识错误和候选索引部分写入。每个用例检查页面清单、段落数量、权限标签、别名和读取指针。只检查抓取 HTTP 成功率不足以证明索引正确。

解析器版本变化会触发受控重建。候选索引记录解析器版本和清洗配置，不能把不同规则产生的段落混在同一快照。抽样查询包括标题、正文短语、版本过滤和权限拒绝。质量未达标时保留旧别名并输出差异报告。

站点凭据更新后先执行只读连接测试，再切换抓取器引用。旧凭据从密钥服务撤销，不写入抓取日志。凭据失效导致站点陈旧，不删除已有页面；查询仍执行最新权限策略。跨域重定向默认拒绝并记录隔离原因。

权限测试区分站点注册、范围编辑、抓取执行、候选批准和搜索使用。候选批准人与范围编辑人职责分离。搜索结果只返回当前用户可查看页面，摘要和高亮同样不能泄露受限正文。缓存包含站点和权限版本。

上线检查包括允许域名、抓取并发、robots 策略、解析器版本、候选阈值和告警。新增站点先以低速模式运行并人工抽样。范围扩大产生新审核，不能通过站点内链接自动越过已批准路径。

搜索评测集按站点、语言、版本和权限级别分层。每次候选切换前运行固定查询，检查正确页面、无权限页面和无结果场景。质量下降时阻止切换，但不会修改站点正文。

站点所有者可以申请删除错误页面缓存。删除请求先验证 URL 和权限，再使查询缓存失效并安排重抓。它不改变源站内容，也不能用于删除其他站点的近似页面。

代码示例块保留语言、页面版本和段落位置，但不会进入代码符号图。搜索可以返回示例文本，影响分析仍以正式代码仓库为准。示例中的占位凭据在解析时脱敏，检测到疑似真实秘密则隔离页面。

多语言页面通过显式替代链接关联，不依据标题相似度自动合并。缺失翻译时搜索可回退到默认语言，但必须标注来源语言和版本，不能把旧版本翻译当作当前规则。

治理报表列出长期陈旧、重复正文、重定向过多和缺少所有者的站点。站点冻结后停止新抓取，现有索引按照权限继续查询；正式下线需要所有者确认和搜索影响评估。
