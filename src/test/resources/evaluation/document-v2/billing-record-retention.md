# 计费记录归档与更正政策

## 账单明细的保留范围

计费记录包括用量明细、价格版本、折扣、税费、结算状态和更正历史。在线账单明细保存十三个月，之后转入归档存储并保存七年。归档期限用于财务核对，不等同于安全审计在线保留周期。客户可见账单只展示汇总和授权明细，内部成本字段不会随普通导出返回。

用量事件写入后先经过去重、归属和价格计算。去重键由来源、资源、时间桶和事件标识组成，不能仅依赖客户端时间。价格计算绑定生效时的价格版本，后续调价不会覆盖历史金额。无法确定归属的事件进入待处理队列，不得随意记入默认项目。

月度结算关闭后，原账单不可直接修改。发现错误时创建更正单，记录原因、原金额、调整金额、证据和批准人。小额更正由计费运营确认，大额更正还需财务负责人批准。更正单形成独立版本并在下期账单体现，不能删除原始明细来隐藏差异。

账单导出文件包含客户可见字段和校验摘要，链接有效十二小时。企业客户可以申请加密归档包，归档包有效四十八小时。链接失效只关闭下载，不删除源账单。重新生成导出沿用相同账单版本并产生新的导出编号，与安全审计文件的有效期没有关联。

查询账单必须限定客户组织和结算周期。项目管理员只能查看被授权项目，财务管理员可以查看组织汇总。跨组织支持需要临时授权和工单，查询结果默认脱敏。缓存键包含组织、角色、周期和账单版本，权限撤销后立即清除相关缓存。

## 归档、保全与恢复

归档任务在账单关闭九十天后将明细复制到归档存储，校验文件数量、记录数、金额合计和摘要。校验通过后在线层只保留索引和必要汇总。归档失败不会删除在线数据，任务从失败分片继续。归档对象采用不可变版本和独立加密密钥。

税务调查或合同争议可以对账单范围设置保全。保全期间暂停归档删除和密钥销毁，但不开放额外查询权限。保全必须记录发起人、依据、范围和复核日期。解除保全后重新计算下一次归档动作，不执行积压操作前先校验范围。

恢复归档数据时先加载索引，再按需读取归档对象。批量恢复需要容量评估，不能为了单个查询恢复整个年度。恢复出来的临时副本设置独立过期时间，到期后删除副本而不是归档原件。摘要校验失败时阻止查询并通知财务平台值班。

审计事件覆盖价格版本发布、账单关闭、更正审批、导出、归档、保全和恢复。审计只记录金额摘要和对象引用，不复制完整账单内容。监控包括待处理用量、结算延迟、更正率、归档积压、摘要失败和跨组织查询。告警不会自动批准更正或缩短保存期限。

测试使用虚构客户、价格和税率，验证跨月边界、价格版本、重复事件、更正链、保全和归档恢复。十三个月、七年、九十天、十二小时和四十八小时只适用于计费域。任何实现不得把这些期限套用到运行遥测、安全审计、账号会话或发布制品。

## 对账契约与验收要求

每日对账比较用量接收、定价结果、账单明细和总账分录。差异按缺失、重复、价格错误、归属错误和税费错误分类。自动修复只允许补发幂等事件，不直接改写关闭账单。需要金额调整时生成更正单并走对应审批。

验收用例覆盖价格在时间桶中间生效、折扣叠加、负向更正、跨币种舍入、组织合并、项目迁移和迟到用量。每个用例检查价格版本、计算明细、账单汇总和总账方向。测试金额使用定点小数，禁止浮点比较掩盖一分钱差异。

迟到用量在账单关闭前进入当前周期，关闭后进入更正流程。系统不能因为事件时间属于旧周期就直接打开已关闭账单。重复迟到事件由原始事件标识去重。无法确认来源的事件继续隔离，不以保持报表完整为由分配给默认客户。

归档索引和对象之间建立双向校验。索引存在但对象缺失时禁止展示下载；对象存在但索引缺失时进入孤立扫描。恢复任务只补建可验证索引，不修改账单金额。密钥恢复失败的归档对象保持不可读并触发财务事故流程。

权限测试验证项目管理员、组织财务、平台支持和审计人员的不同视图。支持人员临时跨组织访问必须引用工单并自动到期。任何导出都使用调用时权限，旧下载链接不会因为角色提升而扩大字段。

上线检查包括价格发布流程、定点精度、归档密钥、总账连接、保全清单和对账告警。价格策略变更必须先用历史样本回放，确认只影响生效时间后的事件。归档周期调整需要财务和合规共同批准。

客户争议处理创建独立案件，引用账单版本和争议明细。案件处理人可以查看必要证据，但不能修改价格版本。达成结论后通过更正单或说明关闭，案件附件遵循客服证据期限，不自动延长全部账单明细。

组织注销时先完成未结账单、退款和税务检查，再关闭客户查询入口。归档记录继续按法定期限保存，访问转交给受限财务角色。注销动作不能批量删除历史更正链。

币种汇率来源、取值时间和舍入规则随账单明细保存。汇率供应商之后修订历史数据时，不自动重算已关闭账单；财务评估差异后决定是否创建更正。缺少汇率的用量进入待处理，不使用上一次汇率猜测。

退款与更正分别建模。退款代表资金流出，更正代表账单事实调整，两者可能关联但不能互相替代。对账报表分别展示原账单、更正、退款和最终余额。
