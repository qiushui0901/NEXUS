# 制品仓库同步与版本清理

## 上游注册和增量同步

制品仓库保存构建产物、容器镜像和依赖包。首次注册上游时校验仓库地址、命名空间、签名策略和只读访问令牌，不检查代码仓库默认分支。连接测试只读取元数据，不下载完整制品。凭据保存到密钥服务，日志和清单只记录凭据引用。

同步游标由上游版本序号和最后成功清单摘要组成，不使用工作区提交或文件修改时间。增量任务先拉取版本目录，再核对签名和摘要，最后下载缺失层。上游返回乱序页面时按照版本序号合并，重复制品由坐标和内容摘要去重。

删除策略分为上游删除、本地过期和管理员隔离。上游删除不会立即清理本地仍被发布引用的制品，只标记来源不可用。没有引用且超过宽限期的制品进入回收队列。重命名坐标视为新制品和旧坐标废弃，不修改历史发布记录。

签名校验失败的制品进入隔离区，不可被构建或发布拉取。重新同步只有在上游提供新签名或管理员确认误报后进行。管理员放行需要安全工单并记录摘要，不能仅按制品名称放行。相同名称的新版本仍独立校验。

同步任务按上游和命名空间隔离，一个上游失败不阻塞其他来源。任务租约防止两个实例同时推进同一游标。旧实例恢复后读取租约版本并退出。分页下载和层上传都使用幂等键，重试不产生重复对象。

## 快照、清理和恢复

每次成功同步生成可查询清单快照，包含坐标、摘要、签名状态和来源版本。新快照完整校验后才替换读取指针。同步失败保留上一快照继续提供查询，并将来源标记为陈旧。陈旧标记不表示已有制品失效。

清理任务先计算发布引用、构建锁和保全状态，再删除未引用对象。对象删除成功后清理索引和缓存。任何引用检查失败都会跳过对象，不允许为了释放空间忽略未知引用。处于安全调查保全的制品暂停清理，但仍可被隔离禁止下载。

灾难恢复从对象存储清单重建索引，再加载最近成功快照。恢复程序按内容摘要校验对象，不能从文件名推断版本。缺失层的制品标记不可用并触发补拉，不影响其他完整制品。读取指针只在快照校验通过后切换。

审计事件包括上游注册、凭据更新、同步、签名失败、管理员放行、快照切换和清理。查询按组织和命名空间过滤。监控包括同步延迟、陈旧来源、隔离制品、缺失层、回收积压和快照校验失败。告警不能自动放行签名异常。

测试使用本地模拟仓库，覆盖乱序分页、重复制品、签名失败、租约切换、引用保护和索引重建。这里的上游版本序号、制品坐标和清单摘要不同于代码仓库的提交起点、文件重命名向量清理和符号关系维护。

## 来源优先级与验收要求

同一制品坐标来自多个上游时，按照组织策略选择来源，并分别保留摘要和签名状态。摘要不同会产生冲突，不允许以后到达的对象静默覆盖。管理员解决冲突时选择可信来源或新坐标，决定绑定策略版本。

验收用例覆盖相同摘要多来源、相同坐标不同摘要、上游分页游标失效、签名证书轮换、发布引用与清理并发和快照切换中断。每个用例检查对象、索引、读取别名和审计事件。仅比较对象数量无法发现错误来源。

证书轮换期间同时信任明确的新旧证书集合，每个集合有到期时间。制品签名按同步时策略验证，策略提高后可启动后台重验。重验失败先隔离新的下载，不删除历史发布所需对象。紧急撤销证书立即阻止相关制品。

对象存储写入成功但索引提交失败时，孤立扫描根据内容摘要发现对象。对象仍被其他坐标引用时保留并补建引用，完全孤立且超过宽限期后回收。索引成功但对象缺失时读取失败并触发补拉，不返回空内容伪装成功。

权限测试区分上游注册、同步执行、隔离查看、放行和清理策略。同步令牌只能访问指定命名空间。放行人与上游维护人需要职责分离。查询用户只能看到有下载权限的制品，聚合容量指标隐藏坐标。

上线检查包括来源优先级、签名根、对象生命周期、引用服务、孤立扫描和告警。新增上游先在候选命名空间验证，不直接进入正式读取别名。策略变更必须回放现有冲突样本。

依赖解析返回确定的坐标、摘要和来源，不接受只有可变标签的生产锁定。可变标签更新产生新的解析结果，但历史构建继续引用原摘要。缓存按组织、命名空间和策略版本隔离。

漏洞扫描结果附着在内容摘要上，同一对象跨坐标复用扫描结论。高危发现可以阻止新下载，但是否撤回历史发布由安全响应流程决定。扫描服务不可用时，高风险命名空间停止引入新对象。

跨区域复制以内容摘要为幂等键，先复制对象，再复制索引，最后确认区域可读。目的区域摘要校验失败时删除损坏副本并重试，不影响源对象。驻留策略禁止的制品不会进入该区域。

容量保护优先暂停低优先级预取，不删除仍有引用的制品。紧急空间回收同样执行引用与保全检查。容量告警不能降低签名要求或跳过候选快照校验。

制品元数据更正只修改描述、许可证或所有者标签，不改变内容摘要。更正保留前后值和操作者，依赖解析缓存按元数据版本失效。需要改变二进制内容时必须发布新坐标或新版本，禁止在原坐标下替换对象。

元数据批量修订先生成差异清单并抽样复核。失败项单独重试，不回滚已经验证的其他制品，也不改变同步游标。
