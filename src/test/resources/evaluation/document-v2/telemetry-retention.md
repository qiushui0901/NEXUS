# 运行遥测数据保留与降采样

## 指标、追踪和事件的保存周期

运行遥测包括服务指标、分布式追踪和非安全类运行事件，不等同于敏感操作审计日志。高分辨率指标在线保存十四天，之后聚合为小时粒度并保存九十天。追踪明细在线保存七天，发生事故且被标记的追踪可以延长到三十天。普通运行事件保存三十天，不承诺作为合规证据。

采集端在写入前移除访问令牌、会话标识和未经批准的用户字段。属性白名单由可观测性团队维护，业务团队新增属性时必须通过隐私检查。发现敏感字段后先停止该属性写入，再启动回溯清理；不能为了排障继续收集。清理只针对违规属性，不删除同一时间段的全部指标。

降采样任务每天处理已超过十四天的高分辨率指标，生成计数、平均值、分位数和最大值。聚合完成并校验后才删除原始序列。校验比较时间桶、标签集合和样本数量，差异超过阈值时暂停删除并告警。处于事故保全中的时间范围跳过清理，保全解除后重新排队。

追踪采样率可以按服务和环境调整，但调整只影响未来数据。事故期间提高采样率需要值班负责人确认，并设置自动恢复时间。恢复默认采样率不删除事故期间已经采集的追踪。追踪导出用于性能分析，下载链接有效两小时，和安全审计导出的有效期不同。

查询接口必须限定组织、环境和时间范围。普通开发者只能查看所属项目的遥测，平台值班人员可以跨项目查看健康聚合，但不能展开包含业务载荷的属性。查询缓存按权限和时间窗口隔离，权限变化后立即失效。跨项目比较使用匿名化服务标识。

## 删除、导出与灾难恢复

遥测删除按数据类型分别执行。指标先删除原始块，再删除索引；追踪先撤销查询目录，再异步回收对象；运行事件按分区淘汰。删除任务记录范围、数量、校验结果和执行节点。任何任务失败都保留可重试游标，不从头扫描导致重复负载。

导出作业只允许选择已经有查看权限的字段和时间范围。导出文件加密保存，链接过期后不能继续下载。导出不改变源数据保留周期，也不因为用户下载就延长数据。事故保全导出由值班负责人发起，并引用事故编号；保全解除不会自动删除已经生成但仍在有效期内的导出。

灾难恢复使用最近完成的元数据快照和对象存储清单。恢复后先校验时间分区，再开放查询，最后恢复清理任务。清理游标必须从快照记录的位置继续，不能因为恢复而重新计算保留期限。若当前时间与快照时间偏差过大，先暂停删除并人工确认。

监控覆盖采集延迟、丢弃属性、降采样积压、删除失败、查询延迟和导出数量。容量告警只触发扩容或采样评估，不允许直接缩短保留周期。修改十四天、九十天、七天或三十天等参数需要可观测性负责人批准并记录生效时间。

测试数据使用合成服务、随机追踪和固定时间轴。测试验证边界时间、保全跳过、降采样校验失败、权限隔离和恢复游标。遥测记录不能替代安全审计记录，运行事件也不能用于证明高风险操作已经获得批准。

## 数据质量与验收边界

每种遥测数据维护独立清单，记录分区、最早时间、最晚时间、样本数、摘要和策略版本。清理任务读取清单而不是扫描查询结果估算范围。清单更新与对象写入通过提交标记协调，未提交分区不进入查询，也不会被提前清理。

验收用例覆盖十四天与九十天边界、夏令时变化、迟到样本、重复追踪、保全范围重叠、属性分类升级和归档对象缺失。测试分别核对原始层、聚合层、查询结果和删除凭证。聚合数值允许规定的浮点误差，但样本数量必须一致。

迟到指标落入已经降采样的时间桶时，系统生成修订聚合并增加版本，不恢复已删除原始序列。查询默认读取最新聚合版本。迟到追踪超过保留窗口则拒绝写入并统计丢弃原因，不能悄悄延长分区生命周期。

隐私字段清理采用属性级重写，完成前查询层屏蔽该属性。重写失败保持屏蔽并进入人工队列。清理凭证记录范围和摘要，不复制被删除值。权限管理员只能调整查看范围，不能取消隐私屏蔽。

性能测试模拟高基数标签、突发追踪和大范围查询，验证容量保护不会改变保留期限。故障测试覆盖清单提交中断、对象写入部分成功、聚合重复和清理游标损坏。恢复必须选择可验证清单，不能猜测最后成功位置。

上线检查包括采集白名单、策略版本、归档桶权限、清理任务并发和告警接收人。保留期调整需要评估容量和合规影响；缩短周期前先完成公告和保全扫描，延长周期也要确认隐私依据。所有变更只从明确生效时间开始。

数据产品使用聚合遥测训练容量模型时，只读取批准的匿名化特征。模型样本拥有独立版本和删除计划，不能因为训练需要永久保留原始追踪。样本构建记录来源时间桶、转换规则和质量摘要。

值班人员添加临时诊断属性时必须设置自动到期。到期后采集端停止写入，历史值仍按原遥测周期清理。延长诊断属性需要重新说明事故或问题编号，不能依靠连续告警无限续期。

跨区域复制只传输批准的数据类型和属性，目的区域执行相同或更严格的保留策略。复制延迟不会延长源区域期限，目的区域也不能因为尚未完成聚合就无限保留原始数据。区域退出前先停止采集，再校验复制和删除凭证。

查询产品展示数据新鲜度和采样率，避免使用者把降采样结果当作完整明细。下载大范围遥测需要异步作业和容量配额，不允许一个查询阻塞清理任务。
