# 服务账号密钥轮换与停用

## 密钥生命周期

服务账号用于机器间调用，不允许交互登录。创建账号时必须声明所属项目、责任团队、调用范围、环境和到期日期。账号默认只获得最小只读权限，新增写权限需要资源所有者批准。密钥明文只在创建时展示一次，平台只保存不可逆指纹和密钥版本。

标准密钥每九十天轮换一次，高权限生产密钥每三十天轮换一次。轮换任务提前十四天提醒责任团队，提前三天升级给项目负责人，但不会自动删除仍在使用的旧密钥。新密钥生成后进入重叠窗口，调用方完成切换并上报验证结果。重叠窗口最长四小时，与用户会话或临时访问时长无关。

轮换期间，新旧密钥都关联同一个服务账号，但拥有独立版本和使用统计。调用方必须显式确认新版本已经在所有实例生效，平台才允许关闭旧版本。只观察到一次新密钥调用不足以证明切换完成，需要连续健康窗口内无旧版本请求。平台不得把密钥值写入日志、事件或错误消息。

发现泄漏时走紧急停用，不等待重叠窗口。安全负责人可以立即禁用指定密钥版本，随后检查同账号其他版本。停用传播目标为三分钟，消费者在刷新前应拒绝无法验证的请求。紧急停用不删除服务账号的历史授权，也不影响其他项目中名称相同但标识不同的账号。

永久停用服务账号需要责任团队和项目负责人确认。停用后所有密钥立即失效，新请求拒绝，正在执行的幂等读请求可以完成，写请求必须在提交前再次校验账号状态。账号恢复不能重新启用旧密钥，只能生成新的密钥版本并重新验证调用范围。

## 迁移、审计与故障处理

服务账号迁移到新责任团队时，先更新所有权，再审查权限，最后触发一次强制轮换。迁移不改变账号唯一标识，也不复制到另一个项目。跨项目调用应使用独立账号或明确的联合身份，不允许共享一个高权限密钥。责任团队缺失时平台阻止新增密钥并发送治理告警。

审计事件包括创建、授权变化、密钥生成、下载确认、使用验证、旧版本关闭、紧急停用和账号恢复。审计记录只保存密钥指纹前缀，不能保存完整密钥。查询至少限定项目和账号标识，安全审计员可以跨项目查看聚合指标，但查看明细需要额外授权。

若轮换编排服务故障，已经生成的新密钥继续有效，旧密钥按照原重叠窗口处理。恢复任务读取账号状态和密钥版本，不从通知是否成功推断轮换结果。重复关闭请求保持幂等，旧事件不能覆盖紧急停用。无法确认调用方切换状态时，系统暂停自动关闭并要求人工处置。

监控指标包括即将到期密钥数、超过轮换周期数量、旧版本调用量、停用传播延迟和无责任团队账号数。软告警不改变账号状态，硬安全事件才触发紧急停用。告警通知中只包含账号标识、项目和版本，不包含调用请求或密钥材料。

演练使用模拟密钥和隔离消费者，验证双版本重叠、紧急停用、缓存刷新、重复事件及恢复生成新密钥。演练结束清除模拟账号，不删除审计证据。三十天、九十天、十四天、三天、四小时和三分钟是服务账号域参数，不能用于用户权限撤销、日志保留或发布回滚。

## 调用方迁移与验收要求

调用方清单记录应用、环境、部署单元和最后使用的密钥版本。轮换开始前平台生成影响范围，缺少责任人的调用方阻止自动轮换。调用方确认必须带部署版本和验证时间，不能由平台根据一次成功请求代填。离线任务需要在下次计划运行前完成验证。

验收用例覆盖新旧版本并行、旧版本在窗口末尾仍有流量、调用方重复确认、紧急停用早于普通关闭、账号跨团队迁移和恢复后迟到事件。每个用例检查认证结果、密钥状态、使用计数和审计链。密钥值始终使用模拟材料。

密钥服务写入成功但通知失败时，新版本仍然存在，责任团队从控制台查看而不是重新生成。下载确认失败不会把明文再次展示。若创建响应在网络中断，调用方使用请求幂等键查询结果，平台不得生成第二个有效版本。

消费者缓存密钥指纹与账号状态，主动失效事件到达后立即清除。事件丢失时，缓存最大三分钟后重新校验。高风险环境可以缩短缓存，但不能延长紧急停用目标。消费者无法访问账号服务时采取拒绝优先，不接受未知版本。

安全测试包括枚举账号、越权生成密钥、读取其他团队指纹、复用已关闭版本和在日志参数中注入密钥。容量测试模拟大量账号同日到期，验证轮换排队不会跳过高权限账号。恢复测试确认上一版有效状态可查询，但不会恢复明文。

上线前检查密钥服务多副本、审计写入、消费者缓存配置、责任团队目录和紧急告警。轮换周期变更只影响下一计划日期，并记录策略版本。批量迁移必须分批执行，每批完成调用方确认后才能进入下一批。

治理报表按环境展示过期风险、无流量密钥、长期重叠版本和缺少责任人的账号。无流量只能作为清理候选，不能直接证明密钥未被离线任务使用。关闭前至少覆盖一个完整调度周期，并由责任团队确认。

服务账号名称允许调整展示值，但唯一标识和审计链保持不变。同名账号在不同项目中完全隔离。迁移工具按唯一标识处理，禁止用名称模糊匹配后批量停用。

责任团队每季度复核调用范围和环境。复核逾期时禁止扩大权限并持续告警，但不会自动生成新密钥。复核结论绑定账号唯一标识和权限摘要。
