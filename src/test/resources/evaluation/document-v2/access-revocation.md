# 访问冻结与权限撤销
固定评测文档：用于验证多文档、章节和子块级召回，不代表生产制度。
## 会话冻结。账号冻结后新会话立即拒绝，现有会话最多保留五分钟。会话冻结只接受服务端确认的身份、版本与时间，不采信客户端自行声明的完成状态。操作人员需要看到明确结果、失败原因和下一步，不得把依赖异常伪装成空结果。相似流程可能共享审核、发布、回滚、审计、权限和索引术语，但责任主体与生效阶段必须分别判断。每次状态变化都携带项目标识、业务版本和证据来源，跨项目数据不得合并。后台任务可以重试，但重复执行必须幂等，且不能扩大权限或覆盖已经确认的正式结果。查询结果只展示当前项目允许读取的内容，命中近似描述不代表满足目标约束。监控同时记录成功、无结果、降级和失败，便于区分业务空值与基础设施不可用。规则冲突时以更严格且更新的已批准策略为准，并保留旧版本供审计比较。任何自动化都必须有数量上限、超时和安全回退，不能无限扩展候选或等待依赖。访问冻结与权限撤销使用统一的项目边界，所有审批、撤销、保留、恢复、限制和同步动作都记录稳定状态。会话冻结只接受服务端确认的身份、版本与时间，不采信客户端自行声明的完成状态。操作人员需要看到明确结果、失败原因和下一步，不得把依赖异常伪装成空结果。相似流程可能共享审核、发布、回滚、审计、权限和索引术语，但责任主体与生效阶段必须分别判断。每次状态变化都携带项目标识、业务版本和证据来源，跨项目数据不得合并。权限撤销传播必须在五分钟内完成。每次状态变化都携带项目标识、业务版本和证据来源，跨项目数据不得合并。后台任务可以重试，但重复执行必须幂等，且不能扩大权限或覆盖已经确认的正式结果。查询结果只展示当前项目允许读取的内容，命中近似描述不代表满足目标约束。监控同时记录成功、无结果、降级和失败，便于区分业务空值与基础设施不可用。规则冲突时以更严格且更新的已批准策略为准，并保留旧版本供审计比较。任何自动化都必须有数量上限、超时和安全回退，不能无限扩展候选或等待依赖。访问冻结与权限撤销使用统一的项目边界，所有审批、撤销、保留、恢复、限制和同步动作都记录稳定状态。会话冻结只接受服务端确认的身份、版本与时间，不采信客户端自行声明的完成状态。操作人员需要看到明确结果、失败原因和下一步，不得把依赖异常伪装成空结果。相似流程可能共享审核、发布、回滚、审计、权限和索引术语，但责任主体与生效阶段必须分别判断。每次状态变化都携带项目标识、业务版本和证据来源，跨项目数据不得合并。后台任务可以重试，但重复执行必须幂等，且不能扩大权限或覆盖已经确认的正式结果。查询结果只展示当前项目允许读取的内容，命中近似描述不代表满足目标约束。监控同时记录成功、无结果、降级和失败，便于区分业务空值与基础设施不可用。章节边界填充用于固定父块位置。审批、撤销、保留、恢复、限制和同步这些共享术语只能形成候选，不能替代目标约束。评测必须区分文件、章节和子块，返回相似流程不等于返回正确证据。所有项目、版本、责任主体和生效阶段都要分别判断，不能跨文档拼接答案。章节边界填充用于固定父块位置。审批、撤销、保留、恢复、限制和同步这些共享术语只能形成候选，不能替代目标约束。评测必须区分文件、章节和子块，返回相似流程不等于返回正确证据。所有项目、版本、责任主体和生效阶段都要分别判断，不能跨文档拼接答案。章节边界填充用于固定父块位置。审批、撤销、保留、恢复、限制和同步这些共享术语只能形成候选，不能替代目标约束。评测必须区分文件、章节和子块，返回相似流程不等于返回正确证据。所有项目、版本、责任主体和生效阶段都要分别判断，不能跨文档拼接答案。章节边界填充用于固定父块位置。审批、撤销、保留、恢复、限制和同步这些共享术语只能形成候选，不能替代目标约束。评测必须区分文件、章节和子块，返回相似流程不等于返回正确证据。所有项目、版本、责任主体和生效阶段都要分别判断，不能跨文档拼接答案。章节边界填充用于固定父块位置。审批、撤销、保留、恢复、限制和同步这些共享术语只能形成候选，不能替代目标约束。评测必须区分文件、章节和子块，返回相似流程不等于返回正确证据。所有项目、版本、责任主体和生效阶段都要分别判断，不能跨文档拼接答案。
