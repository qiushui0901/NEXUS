# 功能开关发布与恢复策略

## 开关变更和灰度控制

功能开关用于控制已经部署代码中的行为，不替代制品发布和配置版本管理。创建开关时必须声明所有者、目标环境、默认值、评估条件、到期日期和回收计划。生产开关默认关闭，只有完成验证后才能逐步扩大流量。永久开关需要架构评审，临时开关到期前必须删除或转为正式配置。

普通灰度变更由功能所有者确认，影响支付、权限或数据写入的开关还需要值班负责人批准。批准记录绑定规则摘要、目标人群和流量比例。修改任一条件都会产生新的变更版本。等待审批超过一小时只发送提醒，不自动开启；紧急止损允许值班负责人直接关闭开关，但不能直接扩大流量。

灰度从内部账号开始，再进入百分之一、百分之十、百分之五十和全量阶段。每个阶段至少观察十五分钟，并检查错误率、延迟和业务护栏。指标缺失或采样异常时停止推进。推进操作只改变开关规则，不重新部署应用。系统记录每个阶段的开始时间、操作者、指标摘要和结论。

自动恢复条件由开关单独配置。错误率连续两个观察窗口超过阈值时，将流量退回上一稳定比例；只有严重错误达到硬阈值时才直接关闭。这里的两个窗口不是应用健康检查失败次数，也不触发制品回滚。自动动作必须记录触发指标和使用的规则版本。

开关关闭后，新请求立即使用默认行为，已经开始的事务按请求开始时快照完成。缓存最长一分钟刷新，关键权限开关采用主动失效。不同项目、环境和租户的规则严格隔离，测试环境的全量开启不能影响生产。客户端缓存只能缩短展示延迟，不能覆盖服务端判定。

## 恢复、清理与审计

开关服务不可用时，SDK 使用最近一次已验证快照。快照超过最大陈旧时间后，安全敏感开关回到关闭，展示类开关保持最后状态。恢复服务时先加载规则版本，再接收实时更新，不能根据通知顺序覆盖更新版本。重复事件按开关标识和版本去重。

错误配置恢复通过发布上一规则版本完成，不修改历史版本。恢复后重新执行目标人群采样和护栏检查。若上一版本引用已经删除的用户组，恢复操作失败并要求人工修正。功能开关恢复不回退数据库、应用制品或已提交业务数据。

到期开关每天扫描，先通知所有者，再阻止新增规则，最后按回收计划删除代码引用和平台配置。仍有流量命中的到期开关不能直接删除，需要创建治理工单。删除后保留名称、所有者、版本摘要和审计索引，避免同名新开关与历史混淆。

审计事件包括创建、审批、灰度推进、自动退回、手动关闭、规则恢复和清理。查询至少限定项目与环境，跨项目只展示聚合。监控包括开关数量、过期开关、快照陈旧度、自动退回和规则发布失败。告警不能自动批准扩大流量。

演练验证服务不可用、陈旧快照、安全默认值、规则版本乱序和缓存失效。演练开关使用专用前缀并只作用于隔离租户。百分之一到全量的阶段和连续两个观察窗口属于功能开关域，不能解释为应用发布需要连续失败三次才回滚。

## 规则评估与验收矩阵

规则评估输入只包含已批准的用户属性、租户、环境和稳定随机种子。随机分桶在规则版本不变时保持稳定，避免用户反复进入和退出实验。属性缺失时使用规则声明的默认分支，不能把未知值当作匹配。敏感属性禁止写入调试日志。

验收用例覆盖百分比边界、规则优先级、用户组变化、缓存陈旧、跨租户同名开关、自动退回与人工关闭同时发生。每个用例检查最终规则版本、命中原因、审计事件和护栏快照。只验证开关布尔值会遗漏错误人群问题。

配置存储提交成功但广播失败时，消费者通过周期拉取获得新版本。广播重试携带相同版本，不能产生第二个规则版本。消费者收到跳跃版本时主动拉取完整快照，不按缺失事件猜测中间状态。旧版本广播永远不能覆盖新版本。

护栏指标服务不可用时暂停扩大流量，当前比例保持不变。安全事故可以人工关闭，但关闭动作仍写入本地可靠日志并在审计恢复后补交。不能因为指标缺失就视为零错误，也不能因为通知超时重复执行退回。

权限测试区分开关查看者、规则编辑者、批准人和值班关闭者。编辑者不能批准自己的高风险规则，值班关闭权限不包含重新开启。跨环境复制只复制草稿，生产仍需独立审核。API 批量操作逐项鉴权并返回稳定结果。

上线检查包括 SDK 最低版本、快照最大陈旧时间、安全默认值、护栏指标和审计外盒。删除开关前通过代码搜索确认引用，搜索不完整时保持治理状态。规则模板更新不会自动修改现有开关，所有迁移都有明确清单。

实验分析使用固定曝光事件，曝光只在规则真正影响请求时记录。重复请求按实验与请求标识去重。分析结果不能直接修改生产规则，负责人需要把结论转成新的规则版本并走审核。

移动端离线缓存具有独立最大年龄，超过后采用安全默认值。客户端重新联网先同步服务端版本，再上报旧曝光。旧曝光只用于分析，不能让已经关闭的开关重新生效。

多区域规则发布先写主区域，再由复制流传播。规则携带全局版本和区域确认状态。未确认区域保持上一稳定版本并显示陈旧，不能自行推进灰度。紧急关闭通过高优先级通道传播，区域恢复后仍以最新全局版本为准。

开关所有者转移时复核到期日期、风险级别和清理计划。没有新所有者的开关进入冻结治理状态，只允许关闭，不允许扩大流量。
